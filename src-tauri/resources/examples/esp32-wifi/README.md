# ESP32 Wi-Fi stub

Minimal Station-mode Wi-Fi connect sketch for ESP32 Dev Module.

1. Edit `src/main.cpp` — set `WIFI_SSID` and `WIFI_PASS`.
2. Build & Upload from Aether.
3. Open Serial Monitor at 115200 baud.

Open in Aether via **File → Open Example…** or the welcome screen.

Platform docs: https://docs.platformio.org/en/latest/platforms/espressif32.html
