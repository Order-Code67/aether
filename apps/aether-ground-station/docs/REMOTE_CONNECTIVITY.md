# Remote Connectivity Architecture (v0.3)

## Цель

Удалённое подключение к Aether Ground Station через интернет: станции в разных точках, масштабирование от 1 до N объектов.

**На текущем этапе:** только архитектура и интерфейсы API.  
**Реализация Remote Gateway / сервера** — отдельный этап после локальной версии.

## Компоненты

| Компонент | Ответственность |
|-----------|-----------------|
| **Remote Client** | UI/SDK оператора: станции, видео, телеметрия, админ разрешённых настроек |
| **Remote Gateway** | HTTPS / WSS вход, маршрутизация сессий, rate limits |
| **Device Registry** | Реестр удалённых станций и их профилей |
| **Authentication Service** | Учётки, MFA, роли, отзыв доступа |
| **Session Manager** | Сессии, лимиты, безопасное завершение, reconnect |
| **Telemetry Service** | Диагностика без подмены `null` на фиктивные значения |
| **Video Relay** | WebRTC + ICE/STUN/TURN, адаптация битрейта |
| **Audit Service** | Журнал входов и действий |

## Сетевой стек

- HTTPS, WSS
- WebRTC + ICE / STUN / TURN
- VPN для защищённого доступа к инфраструктуре (конфигурируется снаружи)
- Авто-reconnect, контроль bandwidth / latency / packet loss

## Безопасность

- Индивидуальные учётки + MFA
- RBAC (оператор / администратор / аудитор)
- Шифрование каналов (TLS / DTLS)
- Audit log, отзыв доступа, лимит сессий
- Защита от replay (nonce / timestamp window)
- Безопасное завершение сессий

Критические функции безопасности оборудования остаются **локальными**.  
Через remote-модуль **не** передаются команды полёта, боевого оборудования, наведения или целеуказания.

## Устойчивость

- Reconnect после обрыва
- Индикаторы latency / loss
- Адаптация качества видео
- Локальная запись при потере интернета
- Отложенная синхронизация журналов

## Масштабирование

Несколько операторов, станций, видеопотоков и аппаратных профилей; централизованные пользователи; **локальная станция работает автономно**, если сервер недоступен.

## Test mode

Все сетевые функции имеют `RemoteTestMode`:

- `disabled` — сеть выключена
- `integration` — реальный gateway (когда будет развёрнут)
- `sandbox` — изолированные вызовы **без** выдачи демо-данных за реальные

Sandbox возвращает явный флаг `synthetic: true` / пустые результаты и никогда не маскирует заглушки под live-телеметрию.
