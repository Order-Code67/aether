Автономный дрон без GPS

Комплектующие · подключение · программирование · чеклист испытаний

Стек: ArduPilot Copter + companion VIO (MAVLink) Aether / DIY · для печати A4
Важно: это не доработка iNav FPV и не optical nav в Aether. Полётный estimator — на companion (OpenVINS / VINS-Fusion и т.п.), поза уходит в EKF Pixhawk. Aether — только лаборатория/отладка.

2. Схема связей

LiPo ──► PDB ──► Pixhawk FC (ArduPilot) ──► ESC ×4 ──► моторы
              │            │
              │            └── TELEM2 / UART MAVLink 921600
              │                         │
         5V BEC ≥3A ──► Companion (RPi / Jetson) ◄── камера вниз (CSI/USB)
                              │              ◄── дальномер (UART/I²C)
                              ▼
                     QGroundControl (USB / Wi‑Fi отладка)

  • UART Pixhawk ↔ Pi: Tx↔Rx перекрёстно, GND общий, только 3.3 V TTL.

  • Вибрации: мягкий маунт FC + жёсткий маунт камеры (по доке VIO).

4. Программирование — полётный контроллер

ШагДействие☐
1Прошить ArduCopter (стабильная ветка) через QGC / Mission Planner☐
2Калибровки: ACC, компас (если есть), радио, ESC, уровень горизонта☐
3Рама: FRAME_CLASS / FRAME_TYPE под квад☐
4Дальномер: RNGFND1_TYPE, порт, RNGFND1_MAX_CM — проверка в HUD☐
5EKF3: позиция/скорость XY из ExternalNav (напр. EK3_SRC1_POSXY=6, EK3_SRC1_VELXY=6) — сверить wiki вашей версии☐
6Приём VISION_POSITION_ESTIMATE / ODOMETRY (параметры VISO_* / VIS_*) — docs ArduPilot Vision Position☐
7Failsafe: потеря RC / vision → Land (не «лететь в никуда»)☐
8Режимы на пульте: Stabilize / AltHold / Loiter / Auto / Land☐
9Логи включены; после каждого теста сохранять .bin☐

5. Программирование — companion (Pi / Jetson)

ШагДействие☐
1ОС: Raspberry Pi OS 64-bit или Ubuntu 22.04 (Jetson — JetPack)☐
2ROS 2 (Humble/Jazzy) или лёгкий стек MAVSDK + VIO☐
3Камера: v4l2 / libcamera, fps ≥ 30, желателен global shutter☐
4Установить VIO: OpenVINS / VINS-Fusion (или готовый пакет под камеру)☐
5Калибровка intrinsics камеры (Kalibr / OpenCV chessboard)☐
6Калибровка extrinsics camera–IMU (Kalibr) — критично☐
7MAVROS / MAVSDK → TELEM2, baud 921600☐
8Публиковать VISION_POSITION_ESTIMATE (102) или ODOMETRY; frame NED/ENU как ждёт Ardu☐
9systemd: автозапуск VIO + MAVLink bridge☐
10Время: chrony / PTP (иначе растут innovations EKF)☐

6. Миссии (земля)

ШагДействие☐
1QGroundControl → подключение к FC☐
2Home = точка взлёта (локальный NED origin при vision)☐
3WP в метрах относительно home (проще без GPS)☐
4Взлёт при уверенном vision fix☐
5Auto только после успешных Loiter-тестов☐
6Посадка: Land / RTL по vision + ручной запасной канал☐

7. Программа испытаний (обязательно)

# Тест Критерий «ок» ☐
1Камера на столе, VIO трекГладкая траектория, loop при возврате☐
2Дрон на привязи, AltHoldВысота стабильна по дальномеру☐
3Loiter по vision 30–60 сУдержание примерно ±0.5–1 m☐
4Квадрат Auto 5×5 mОшибка на углах приемлема☐
5Закрыть объектив (потеря vision)Failsafe Land, без улёта☐
6Вибрации на ховереEKF innovations в норме☐

Пока п.3–4 не стабильны — миссию в поле не грузить.

8. Чеклист заказа

  • Pixhawk-совместимый FC + ArduCopter
  • Raspberry Pi 5 / Jetson + microSD
  • BEC 5 V ≥ 3 A для companion
  • Global-shutter камера вниз + кабель
  • Дальномер вниз + проводка
  • ELRS RX
  • Рама, моторы, ESC, пропы, LiPo
  • Кабель TELEM2 ↔ UART Pi (Tx/Rx/GND)
  • Ноут + QGroundControl
  • GPS-модуль для базы (опц.)
  • FPV-линк отдельно от VIO (опц.)
